IBGE Data Downloader

Welcome to the IBGE Data Downloader plugin help. This plugin allows you to easily browse, search, and download data directly from the IBGE (Brazilian Institute of Geography and Statistics) data repositories.

Help Topics

  • Browsing and Selecting Data
  • Searching for Data
  • Downloading and Post-processing

Overview

The main dialog is divided into a few key areas:

  1. Data Source Tabs: Switch between 'Geospatial Data' and 'Statistical Data'.
  2. Product Tree: Navigate the directory structure of the selected data source.
  3. Search Panel: Find specific products by name.
  4. Download Options: Configure the output directory and post-download actions like unzipping files and adding layers to the map.
