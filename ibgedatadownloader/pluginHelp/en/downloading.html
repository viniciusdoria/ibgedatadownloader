Downloading and Post-processing

Starting the Download

  1. Select Files: First, select the files you wish to download.
  2. Choose Output Directory: Click the [...] button next to the Output directory field and select a folder on your computer where the files will be saved.
  3. Click OK: The 'OK' button will become active once you have selected at least one file and an output directory. Click it to start the download process.

A progress dialog will appear, showing the download status.

Post-processing Options

Before starting the download, you can enable the following options:

  • Unzip downloaded file(s): If the downloaded file is a .zip or .tar archive, the plugin will automatically extract its contents into the output directory. This option is only enabled if you select a compressed file.
  • Add layer to project after download: If the "Unzip" option is also enabled and a Shapefile (.shp) is found within an extracted archive, it will be automatically added as a new layer to your QGIS project.
