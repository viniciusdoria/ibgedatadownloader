Browsing and Selecting Data

Navigating the Product Tree

The Products Tree allows you to navigate the IBGE data repositories. The data is organized into two main tabs: Geospatial Data and Statistical Data.

Click the arrow next to a folder to expand it and view its contents. The plugin will fetch the directory listing from the server in real-time.

Selecting Files for Download

To select a file for download, simply click the checkbox next to its name. You can select multiple files from different directories. Only items that are files (not directories) will have a checkbox.

The number of selected products is shown at the bottom of the tree view. You can use the Uncheck All button to clear your selection.
