Searching for Data

The search panel helps you find products quickly without manually browsing the entire tree.

How to Search

  1. Select Data Source: Use the radio buttons (Search in Geospatial Data or Search in Statistical Data) to choose which repository to search.
  2. Enter a Keyword: Type your search term in the Search for field.
  3. Choose Search Type:
    • Contains: If checked, the search will find all items whose names contain the keyword.
    • Similarity: If 'Contains' is unchecked, the search uses a string similarity algorithm. You can set the minimum similarity score (0-100) for a match. A higher value means a stricter match.
  4. (Optional) Limit Search Scope: To search only within a specific directory, first select that directory in the product tree, then check the Search in selected item only box.
  5. Start Search: Click the Search button.

Search Results

After the search is complete, the product tree will automatically expand to show the found items, which will be highlighted in yellow. This may take several minutes depending on the search scope.
