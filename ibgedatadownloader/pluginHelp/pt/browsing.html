Navegando e Selecionando Dados

Navegando na Árvore de Produtos

A Árvore de Produtos permite que você navegue pelos repositórios de dados do IBGE. Os dados são organizados em duas abas principais: Dados Geoespaciais e Dados Estatísticos.

Clique na seta ao lado de uma pasta para expandi-la e visualizar seu conteúdo. O plugin buscará a listagem de diretórios do servidor em tempo real.

Selecionando Arquivos para Download

Para selecionar um arquivo para download, simplesmente clique na caixa de seleção ao lado de seu nome. Você pode selecionar múltiplos arquivos de diferentes diretórios. Apenas itens que são arquivos (e não diretórios) terão uma caixa de seleção.

O número de produtos selecionados é mostrado na parte inferior da árvore. Você pode usar o botão Desmarcar Todos para limpar sua seleção.
