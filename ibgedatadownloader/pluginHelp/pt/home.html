IBGE Data Downloader

Bem-vindo à ajuda do plugin IBGE Data Downloader. Este plugin permite que você navegue, pesquise e baixe dados facilmente, diretamente dos repositórios de dados do IBGE (Instituto Brasileiro de Geografia e Estatística).

Tópicos de Ajuda

  • Navegando e Selecionando Dados
  • Pesquisando por Dados
  • Download e Pós-processamento

Visão Geral

A janela principal é dividida em algumas áreas principais:

  1. Abas de Fonte de Dados: Alterne entre 'Dados Geoespaciais' e 'Dados Estatísticos'.
  2. Árvore de Produtos: Navegue pela estrutura de diretórios da fonte de dados selecionada.
  3. Painel de Pesquisa: Encontre produtos específicos por nome.
  4. Opções de Download: Configure o diretório de saída e as ações pós-download, como descompactar arquivos e adicionar camadas ao mapa.
